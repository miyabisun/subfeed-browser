# subfeed-browser

動画の一覧ページから動画を選び、YouTube自身の画面で見て、戻るで一覧へ帰るためのAndroidアプリです。
[youtube-sub-feed](https://github.com/miyabisun/youtube-sub-feed)（登録チャンネルの動画を新しい順に並べる、自分で動かすWebアプリ）の一覧と組み合わせて使います。

動画を選ぶたびにYouTubeアプリへ切り替わり、一覧を開き直す手間をなくします。
視聴・高評価・コメントは、アプリ内に映したYouTubeのWebページ（m.youtube.com）で行います。
YouTubeアプリも、ほかのブラウザも経由しません。
YouTubeのページからは、YouTubeアプリへの誘導、下のタブ、Shortsの棚、動画の下のおすすめを取り除きます。
動画を開いている間も、一覧のヘッダー（グループの切り替えやメニュー）は画面の上に出たままで、そのまま使えます。
電話を横向きにすると、動画を画面いっぱいに出します。

ブラウザの部分は[GeckoView](https://mozilla.github.io/geckoview/)（FirefoxのエンジンをAndroidアプリへ組み込む部品）です。

## 必要なもの

- Android 16以降の、arm64の電話かタブレット。
- 動画の一覧を出すWebページ。下の「[一覧のページとの取り決め](#一覧のページとの取り決め)」に対応していると、
  開いた動画を「もう見た」にするなどの処理をページ側で続けられます。
  対応していない一覧でも、YouTubeへの通常のリンクはこのアプリのYouTubeの画面で開きます。

## インストール

[最新リリース](https://github.com/miyabisun/subfeed-browser/releases/latest)のAssetsから
`subfeed-browser-vX.Y.Z.apk`（約200MB）をダウンロードし、端末で開いてインストールします。
提供元の許可を求められたら、Androidの案内に従ってください。
PCから入れる場合は、[ADBでのインストール](docs/development.md#adbでのインストール)を参照してください。

配布APKは開発用のdebug鍵で署名しています。ファイルの確かめ方と更新の注意も、上の手順にあります。

## 使い方

1. 初めて開くと、一覧のURLを尋ねます。一覧のページのURLを入力して「保存」を押します。
   `https://` を省くと、httpsのアドレスとして扱います。
2. 一覧が開きます。サインインが必要な一覧なら、そのサインインの画面がそのまま出ます。
3. 一覧で動画を選ぶと、YouTubeの画面が開き、再生が始まります。
   一覧のヘッダーは上に出たままで、YouTubeの画面はその下に出ます。
4. YouTubeの画面の左上の「←」か端末の戻るを押すと、YouTubeの中で1つ前のページへ戻ります。戻る先が無くなると一覧に帰ります。
   一覧では一覧の中を戻り、戻る先が無くなるとアプリを閉じます。
5. ヘッダーは、動画を開いたまま使えます。メニューを開くと、開いている間だけYouTubeの画面がメニューの下へ下がります。
   別のグループやメニューの項目を選んで一覧が別のページへ移ると、YouTubeの画面を閉じて、そのページを出します。
6. YouTubeの画面で、ページの先頭から下へ引っ張って離すと、開いているページを読み直します。
   高評価の数やコメントを最新にできます。

ヘッダーが出たままになるのは、下の取り決めの目印を付けた一覧です。目印の無い一覧では、YouTubeの画面が全面に出ます。
「←」は、YouTubeのロゴの場所に出します。ロゴからYouTubeのトップへ移って、開いた動画から離れないようにするためです。YouTubeの検索とメニューは使えます。

電話（画面の短い辺が600dp未満の端末）を横向きにすると、動画のページは動画だけを画面いっぱいに出します。
一覧のヘッダーとシステムのバーは隠れ、動画の左右（画面が動画と同じ形に近いときは上下）に帯が空きます。
帯の左上に「←」、右下に高評価とコメントの印が出ます。高評価はYouTube自身のボタンを押し、押してある間は印が塗られます。
コメントの印を押すと、YouTube自身のコメント欄が右に開き、動画は左へ縮みます。同じ印かコメント欄の✕で閉じます。
縦向きに戻すと、ヘッダーとYouTubeのページの表示に戻ります。

タブレットを横向きにしたときなど、YouTubeが動画の右に列を空ける幅では、その列にコメント欄を開いておきます。
✕で閉じるとその動画では開き直さず、コメント欄の中を下へ引いてもページは読み直しません。

引っ張って読み直せるのは、ページの先頭で、動画のプレイヤーの外を引いたときです。読み直している間は、上に回る印が出ます。
ページを下へ読み進めた位置、全画面の再生中、Googleのログインのページでは読み直しません。
Shortsの上下のスワイプは、Shortsの切り替えのままです。上にもうShortsが無いときに下へ引くと、読み直すことがあります。
一覧の画面には、アプリの側の引っ張って更新はありません。一覧のページが自分で持つ操作が、そのまま動きます。

高評価やコメントをするには、YouTubeの画面でYouTubeにログインします。
ログインしていない状態で高評価を押すと、YouTubeがログインを案内します。
一覧のページが新しい窓で開くGoogleのページ（youtube-sub-feedの「チャンネル同期」の同意など）も、アプリの中で開きます。
YouTubeの画面と同じログインを使うので、アプリの中で1回ログインすれば、どちらにも効きます。窓は用が済むと自分で閉じ、戻るでも閉じられます。

動画の全画面ボタンでYouTube自身の全画面になり、戻るで解除します。全画面の間は、一覧のヘッダーも隠れます。端末を横にしても再生は続きます。
一覧やYouTubeのページの選択欄（`<select>`）と確認（`alert`・`confirm`）は、端末のダイアログで出します。
アプリを離れると再生は一時停止します。戻ったあとは、再生ボタンで再開してください。

一覧のURLを変えるには、ホーム画面のアプリのアイコンを長押しして「一覧のURL」を選びます。
一覧を開けなかったときの画面にも「URLを変更」があります。

一覧やYouTubeを開けなかったときは、Wi-FiやVPNの接続を確かめてください。
つながると、アプリが自分で読み込み直します。アプリへ戻ったときにも読み込み直します。「再試行」でも読み込めます。

### リンクの扱い

| リンク | 開く場所 |
| --- | --- |
| 一覧にあるYouTubeの動画 | アプリのYouTubeの画面 |
| YouTubeの中のリンク（別の動画、チャンネル）とGoogleのログイン | アプリのYouTubeの画面 |
| 一覧のページが新しい窓で開くGoogleのページ（ログイン、同意） | アプリの中の窓。開いた一覧のページとつながったままで、閉じると元の画面に戻ります |
| YouTubeの説明欄などにある、ほかのサイトへのリンク | 端末の既定のブラウザ |
| 一覧にある、新しいタブで開くほかのサイトへのリンク | 端末の既定のブラウザ |
| `intent:` や `vnd.youtube:` など、ほかのアプリを開くためのリンク | 開きません |

## 一覧のページとの取り決め

一覧のページが動画を開く役をこのアプリへ渡すための取り決めです。

- アプリは、YouTubeとGoogle以外のページの `<html>` に、ページの読み込みの最初で `data-video-host="1"` を付けます。
  ページは、この属性でアプリの中にいることが分かります。
- ページは、動画を開くときに次のメッセージを自分自身へ送ります。

  ```js
  window.postMessage(
    {
      source: 'youtube-sub-feed',
      type: 'open-video',
      id: '<動画ID>',
      url: 'https://www.youtube.com/watch?v=<動画ID>',
    },
    location.origin,
  )
  ```

- アプリは、一覧の画面の最上位のページが自分自身へ送ったメッセージだけを受け取ります。
  `url` がYouTube（`youtube.com`・`youtu.be`）のhttp(s)のアドレスのときだけ開き、それ以外は無視します。
  `/shorts/<動画ID>` のアドレスも開けます。`id` は使いません。
- アプリは一覧のAPIを呼びません。「もう見た」にする処理などは、ページの側で行ってください。
  一覧のページは、YouTubeの画面の裏でも動き続けます。
- ページは、動画を開いている間も出しておく部分（ヘッダーなど）に `data-video-host-keep` を付けられます。

  ```html
  <header data-video-host-keep>…</header>
  ```

  アプリは、その要素の下端までを一覧の画面として残し、YouTubeの画面をその下に出します。
  要素の高さや位置が変わると、YouTubeの画面の位置も追従します。
  その要素の中を押した操作は、ページにそのまま届きます。押しただけでは、アプリはYouTubeの画面を閉じません。
  要素からはみ出して開く部分（ヘッダーの下に出るメニューなど）があれば、開いている間、YouTubeの画面をその下端まで下げます。
  ページが別のアドレスへ移ると（`history.pushState` を含みます）、アプリはYouTubeの画面を閉じて一覧を出します。
  要素はページの上端に置いてください。下端が画面の高さの5分の1を超えるとき（横向きでキーボードを出したときなど）、
  全画面の再生中、電話の横向きの動画のページ、この属性が無いページでは、YouTubeの画面を全面に出します。
- ページが `window.open` などで開くGoogle（`google.com`・`google.co.jp`）のアドレスの窓は、アプリの中で開きます。
  窓からは `window.opener` で元のページへ答えを返せます。Google Identity Servicesの同意の窓は、そのまま動きます。

## 制限

- ブラウザのエンジンを含むため、APKは約200MBあります。arm64以外の端末では動きません。
- Googleは、アプリに組み込んだブラウザからのログインを制限することがあります。
  このアプリはFirefoxと同じエンジンを使い、名乗り（User-Agent）を書き換えませんが、ログインできるかどうかはGoogleの側の判定によります。
- Android 17以降では、家庭内LANのアドレス（`192.168.x.x` など）にある一覧を開けないことがあります。
  アプリがLANへの接続の許可を求めないためです。
- ページが出すファイルの選択、カメラやマイクの許可、ダウンロード、長押しのメニューには対応していません。
- バックグラウンド再生と小窓（PiP）には対応していません。
- OSの明暗を切り替えると、再生中の動画は一時停止します。
- YouTubeから取り除く部分は、YouTubeのページの作りに合わせて書いています。
  YouTubeの側が変わると、取り除いた部分が再び出ることがあります。

## データの扱い

ログインの情報（Cookie）と一覧のURLは、端末のアプリの領域にだけ保存します。
アプリの作者や第三者のサーバーへは送りません。Androidのバックアップと端末間の移行の対象からも外しています。
アプリを削除すると、ログインも消えます。

ログインを預かるアプリなので、新しいリリースが出たら更新してください。ブラウザのエンジンの修正を含みます。
